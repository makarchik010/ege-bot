# Задание №8. Комбинаторика и перебор слов

**Сложность:** Базовая / Средняя  
**Первичный балл:** 1  
**Основной инструмент:** Библиотека `itertools` (методы `product` и `permutations`)

---

### 1. Главная развилка алгоритма

В 8 номере всегда два типа условий:
1. **Буквы МОГУТ повторяться** (слова составляются из заданного алфавита) ➔ используем `itertools.product`.
2. **Каждая буква используется ровно 1 раз** (анаграммы, перестановки) ➔ используем `itertools.permutations`.

---

### 2. Универсальный шаблон (`product`)

```python
from itertools import product

# repeat = длина итогового слова
words = product('ВИШНЯ', repeat=6)

count = 0
for w in words:
    s = ''.join(w)  # превращаем кортеж ('В', 'И', ...) в строку 'ВИШНЯ...'
    
    # Условие задачи: 'В' встречается ровно 1 раз, а буква 'И' не стоит на первом месте
    if s.count('В') == 1 and s[0] != 'И':
        count += 1

print("Итого подходящих слов:", count)
